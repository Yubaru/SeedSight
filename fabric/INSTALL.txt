SeedSight 1.1.0 - Minecraft 26.2 / Fabric

1. Select a Minecraft 26.2 instance using Fabric Loader 0.19.3 or newer.
2. Install Fabric API 0.158.0+26.2 or newer.
3. Remove previous WorldFinder and SeedSight JARs from that instance's mods folder.
4. Copy the single SeedSight JAR from this archive's mods folder into the mods folder.
5. Start Minecraft and press M. Choose a structure or POI, open its waypoint menu, and select
   Built-in navigation. Follow the compact arrow above the hotbar.

The waypoint completes after you remain within 12 horizontal blocks briefly. SeedSight plays the
Minecraft level-up sound and removes it automatically. Use /wf waypoint clear to cancel it.

To record a place you already visited, open that POI's marker menu and choose Not visited - check off.
Open it again and choose Visited - uncheck to undo the check. Visited checks are saved separately for
each world or multiplayer server.

Multiplayer seed mapping requires the known server seed.
